\# 🤖 LLM Benchmark Repository



\*\*A lightweight, low-end friendly repository for benchmarking various LLMs.\*\*



\## ✨ Purpose

This repository is designed to benchmark Large Language Models (LLMs) across sizes ranging from \*\*1B to 35B (Q4 quantization)\*\*. The goal is to provide a practical and accessible tool for evaluating model performance without requiring high-end hardware.



\## ⚙️ Low-End Friendly Setup

\*   \*\*Target Audience:\*\* Low-end users.

\*   \*\*Recommended Setup:\*\* 8GB VRAM (e.g., RTX 4060) and 16GB DDR5 RAM.



\## 📚 Benchmark Details

\*   \*\*Questions Source:\*\* Questions were generated by \*\*Claude Fable 5.1\*\*.

\*   \*\*Evaluation Type:\*\* Simple Question-Answer evaluations.



\## 🛠️ Key Components (Scripts)

The repository includes three core scripts:

1\.  `benchmarker.py`: Automatically asks the LLMs each question and collects their responses.

2\.  `evaluator.py`: Used after benchmarking is complete. Displays the question, all LLM responses, and the intended answer, prompting you to provide a score for evaluation.

3\.  `visualizer.py`: Takes the collected evaluation results and visualizes them across \*\*5 neat graphs\*\*.



\## 🗂️ Configuration (`config.json`)

All primary settings are managed in `config.json`, which includes:

\*   \*\*Model \& API:\*\* List of models to benchmark (`models`), model names for display (`model\_names`), OpenAI-compatible endpoint address (`address`).

\*   \*\*Parameters:\*\* Token limits (`max\_tokens`), thinking toggle (`thinking`), and `temperature`.

\*   \*\*Prompts:\*\* Global LLM system prompt (`system\_prompt`).

\*   \*\*Benchmark Data:\*\* Benchmark questions, intended answers, and maximum scores (`questions`). \*Note: This supports reading from local files using the format: `{file:path/to/local/file.txt}`.\*

\*   \*\*OpenRouter:\*\* Settings required for the `/ai` command.



\## 📁 Folder Structure

\*   `results/`: Stores raw benchmark run results.

\*   `evaluations/`: Stores evaluation scores and final evaluation data.

\*   `scripts/`: \*\*(IMPORTANT)\*\* This folder contains \*tool scripts\* used to assist in evaluation (e.g., `q4.py` to verify LLM code, `ai.py` for OpenRouter queries). \*\*It does NOT contain the main benchmark code.\*\* Includes a `how\_to\_use.txt` file.
